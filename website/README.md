# @inup/website

Landing page for [inup](https://github.com/donfear/inup), built with Astro and deployed to GitHub Pages by `.github/workflows/website.yml`.

- `pnpm dev` — local dev server
- `pnpm build` — static build to `dist/`

Scaffolded with `create astro` (minimal template); see `AGENTS.md` for Astro conventions.
